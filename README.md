# Evergreen Love Studio

Editor paramétrico para diseñar piezas de corte láser (xTool P2S): cajas con dedos, tapas deslizantes, cajones, divisiones, grabado de nombres y logos, vista 3D y exportación SVG/DXF.

Funciona completo en el navegador, sin servidor ni cuentas. Los diseños se guardan en el navegador y como archivos `.json`.

Librerías incluidas en `lib/`: Clipper (Boost Software License), Three.js r128 y OrbitControls (MIT).

Sitio publicado: https://evergreenlov.github.io/lingomaster-mandarin/ (se sirve desde la carpeta `docs/`).
